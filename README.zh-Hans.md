## 开发

### 前置要求

- [Rust](https://www.rust-lang.org/)（最新稳定版）
- [Task](https://taskfile.dev/)（可选）

### 构建

```sh
cargo build
```

### 测试

```sh
cargo test
```

### 运行

```sh
cargo run
```

### 安装

```sh
cargo install --path d1v-cli
```

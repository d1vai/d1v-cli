# D1V CLI

Experimental CLI for [d1v.ai](https://www.d1v.ai/).

</div>

## Development

### Prerequisites

- [Rust](https://www.rust-lang.org/) (latest stable)
- [Task](https://taskfile.dev/) (optional)

### Build

```sh
cargo build
```

### Test

```sh
cargo test
```

### Run

```sh
cargo run
```

### Install

```sh
cargo install --path d1v-cli
```
